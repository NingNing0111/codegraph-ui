# Codegraph UI

Codegraph UI 是一个本地运行的代码库知识图谱可视化工具，用于打开代码分析生成的 SQLite 数据库，浏览其中的 files、nodes、edges，并在图上查看节点关系和源码片段。

## 功能

- 本地启动 Web UI，自动打开浏览器。
- 读取 SQLite 数据库中的 `files`、`nodes`、`edges` 表。
- 支持按名称、路径、语言、节点类型过滤。
- 使用 ECharts Canvas 渲染代码关系图。
- 点击节点查看签名、文档、源码位置和源码片段。
- 支持拖拽调整详情面板宽度。

## 安装与运行

需要先安装 Rust 工具链。

```bash
cargo run --release
```

启动后终端会输出本地访问地址，并尝试自动打开浏览器。

## 使用方式

1. 在“数据库文件”输入框中填写 SQLite db 文件的绝对路径。
2. 在“项目根路径”输入框中填写被分析项目的根目录绝对路径。
3. 点击“加载图谱”。
4. 可通过搜索框、语言过滤、节点类型过滤缩小图谱范围。
5. 点击图中的节点查看详情和源码片段。

如果源码文件路径在数据库中已经是绝对路径，可以不填写项目根路径。若数据库中记录的是相对路径，源码片段会按“项目根路径 + 数据库中的文件路径”来定位。

## 数据库要求

SQLite 数据库需要至少包含以下表或视图：

- `files`
- `nodes`
- `edges`

可选表或视图：

- `unresolved_refs`

`nodes` 表需要包含节点 ID、类型、名称、文件路径、语言、起止行号等字段；`edges` 表需要包含 source、target、kind 等关系字段。

## 构建发布包

```bash
./scripts/build-release.sh
```

发布构建产物位于 `target/release/codegraph-ui`。

## 注意事项

- 浏览器出于安全限制通常不会提供所选文件的绝对路径，因此 db 路径和项目根路径都通过文本输入。
- 大仓库建议先使用搜索框限定目录或文件名，并选择较小的节点上限。
- UI 依赖 CDN 加载 ECharts，需要能访问 `cdn.jsdelivr.net`。
